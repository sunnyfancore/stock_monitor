# 盯盘小窗 2.0（stock_monitor）· 纯 Win32 原生版

任务栏盯盘小组件。2.0 起完全去掉 Qt 和 requests，**只用 Python 标准库 + ctypes 直接调用 Win32 API**：
预计 exe 约 8~12MB（旧版约 34MB）、内存约 20MB 级（旧版约 80MB），无第三方依赖（以实际打包结果为准）。

## 任务栏：原生嵌入（不再是“盖在上面”）

任务栏条作为 `Shell_TrayWnd` 的**子窗口**创建，真正长在任务栏里（与 TrafficMonitor 同一做法）：

- **Win10**：把任务按钮区（`MSTaskSwWClass`）缩窄让出位置，任务按钮自动重排，绝不重叠；退出时自动还原
- **Win11**：嵌在托盘区左侧
- 跟随任务栏一起自动隐藏 / 显示；全屏游戏、视频时随任务栏让位，不再需要“强制置顶”
- 文字逐像素 Alpha 抗锯齿（`UpdateLayeredWindow`），背景完全透明，深浅色任务栏自动换字色
- Explorer 重启、分辨率 / 缩放 / 深浅色变化、睡眠唤醒都会自动重建和重新贴靠
- 如果某台机器嵌入失败，会自动回退到“悬浮覆盖（兼容模式）”；也可以在右键菜单「任务栏显示」里手动切换

## 任务栏盯哪只（右键菜单「任务栏盯哪只」）

- **固定盯一只**：菜单「任务栏盯哪只 → 固定盯一只」里直接列出全部自选，点哪只就固定显示哪只（会自动停止轮播）；
  也可以在面板里单击某只。面板左侧蓝色竖条标记任务栏当前显示的那只
- **轮播**：鼠标停在任务栏条上时暂停；轮播中在面板里单击某只会跳到它并从它继续轮
  （若它不在轮播范围内，则临时显示一个周期后回到轮播）
  - **轮播间隔**：2 / 3 / 5 / 8 / 10 / 15 / 20 / 30 / 60 秒，或「自定义秒数…」手动输入 1~3600
  - **轮播数量**：全部自选，或只轮前 2 / 3 / 5 / 8 / 10 只，或「自定义数量…」手动输入（0 = 全部）；
    按面板顺序取前 N 只，右键行可上移/下移/移到最前调整
  - 手动输入时面板底部输入框切换为设置输入，标题旁会提示正在设置什么；回车保存，Esc 取消，输入不合法会闪红
- **任务栏显示名称**：独立开关，在涨跌行前加短名称（如「茅台 ↑2.81%」），固定和轮播都适用；
  隐私模式下显示序号（#1、#2…），网速伪装下不显示
- **自定义别名**：右键面板里某只 →「设置别名…」，底部输入框变成别名输入，回车保存、留空清除、Esc 取消（最多 8 个字）。
  设置后任务栏（开启显示名称时）和面板都优先显示别名，面板第二行保留「代码 · 原名」便于对照；隐私模式下也显示别名

## 涨跌颜色（右键菜单「涨红跌绿着色」）

默认不着色（全白 / 跟随系统文字色）。勾选后标准涨红跌绿：任务栏两行（价格 + 涨跌幅）整体着色，面板里价格和涨跌幅同样着色；
隐私模式、网速伪装下始终为中性色。所有文字均为常规字重，任何模式都不使用粗体。

## 面板：悬浮 / 常驻 / 拖拽

- 鼠标在任务栏条上停留约 0.2 秒 → 弹出面板，移开自动收起
- **常驻**：单击任务栏条，或点面板右上角的 📌 → 面板常驻不收起；再点一次取消
- **拖拽**：按住面板标题栏拖到任意位置，松手即常驻在那里，位置自动记忆（多显示器、分辨率变化后会自动拉回屏幕内）
- 「面板总在最前」可在菜单里开关（关掉后就像一个桌面小部件）
- 行内操作：单击行 → 显示到任务栏；悬停点 × → 删除；右键行 → 上移 / 下移 / 移到最前 / 删除；滚轮滚动
- **搜索添加**：底部输入框直接输入 名称 / 拼音首字母 / 代码，列表区实时变成搜索结果
  （如 `茅台`、`zgpa`、`腾讯`、`apple`、`00700`），覆盖 A 股、港股、美股、指数、ETF/基金
  - ↑↓ 或滚轮选择，回车 / 单击添加；结果还没出来就按回车，会在结果返回后自动添加第一条
  - 已在自选的显示「已添加」，选中它会直接设为任务栏显示
  - Esc 清空搜索、回到自选列表
  - 仍支持一次粘贴多个代码（空格或逗号分隔）：`600519 hk00700 AAPL`
- 面板跟随系统深浅色和强调色；Win11 下原生圆角和阴影

## 伪装（多种方式）

| 方式 | 效果 | 操作 |
|---|---|---|
| 正常显示 | 价格 + 红绿涨跌 | — |
| 隐私模式 | 无股票名称、无红绿，只剩中性颜色的数字（如 `1758.20` / `+0.53`）；托盘图标换成通用图标 | 面板眼睛图标 / 菜单「伪装」 |
| 网速监视器伪装 | 任务栏显示 `1758.20 K/s` / `↑ 0.53 K/s`，面板变成“网络监视”，股票名换成 svchost.exe 等进程名 | 同上 |
| 老板键 | 一键隐藏任务栏条、面板和托盘图标，再按一次恢复 | `Ctrl+Alt+Z` |
| 循环切换伪装 | 正常 → 隐私 → 网速 | `Ctrl+Alt+X` |

伪装模式下托盘图标会换成蓝色柱状“监视器”图标，提示文字为“网络监视器”/“数据面板”；
如果想彻底隐藏，可勾选「伪装 → 伪装时隐藏托盘图标」（所有功能在任务栏条右键菜单里都有）。
Win11 新托盘图标默认收在「^」里，可直接拖到任务栏，或在 设置 → 个性化 → 任务栏 → 其他系统托盘图标 中打开。

两个快捷键可在配置文件 `boss_key` / `disguise_key` 中修改（如 `"Ctrl+Shift+F9"`）。
老板键隐藏后如果忘了快捷键，**再双击一次 exe 就会恢复显示**。

## 稳定性

- 网络请求在独立工作线程里进行（长连接复用、超时 4 秒），界面线程永不卡顿；20 秒无响应自动重建线程
- 失败时 2~10 秒递增重试；开盘中长时间没拿到新数据，面板标题旁提示「数据延迟 xx 秒」
- **节假日自动识别**：不需要维护节假日表——开盘半小时后（A股 9:45 / 港股 10:00 / 美股美东 10:00）若该市场
  所有自选的行情时间仍停在前一交易日，即判定今天休市，当天不再请求该市场
- **美股按夏令时精确换算**开盘时段（美东 9:30-16:00）
- **启动秒显**：退出时保存最后一次行情（`cache.json`），下次启动立即显示上次收盘价，联网后再更新
- 自选很多时每 60 只分批请求，避免 URL 过长
- **锁屏 / 老板键隐藏时暂停请求**，解锁或恢复显示时立即刷新一次
- **Win10 任务栏实时让位**：监听 Explorer 任务栏布局变化（打开/关闭窗口、托盘图标增减），约 30ms 内重新贴靠，
  不再出现短暂重叠
- 开机自启时如果任务栏尚未加载，会等任务栏就绪后再嵌入，不会误退回覆盖模式
- **休市不联网**：自选涉及的市场全部休市（含 A 股 / 港股午休、周末）时完全停止请求，到下一个开盘时间自动恢复；
  启动、添加新票、手动刷新、睡眠唤醒时仍会取一次最新收盘价。自选里有场外基金时，工作日 18:00~23:30 每 30 分钟查一次净值
- 单实例；配置原子写入；窗口过程异常全部捕获并写日志，不会崩溃退出
- 日志：`%APPDATA%\StockWatcher\log.txt`

## 加密中转（防抓包，隐藏域名和内容）

- 默认直连腾讯接口，**全部走 https**：抓包只能看到 `gtimg.cn` 域名，看不到查询了什么
- 若连域名也要隐藏、并防止公司根证书/抓包工具做中间人解密：部署 `server/` 下的中转服务
  （GitHub Actions 自动构建镜像 `ghcr.io/sunnyfancore/stock-relay`，服务器上用 docker compose 部署，
  可选 nginx 反代，见 [server/README.md](server/README.md)），然后
  右键任务栏条 → **加密中转 → 设置连接串…**，粘贴服务器日志里的 `swr://…`，回车
  - 推荐方式：在现有网站里加一个反代路径（共用 443 和网站证书），连接串 `swr://令牌@你的域名/路径`；
    客户端**只用自带的公共根证书清单**校验证书，公司 / 抓包工具装进系统的根证书无效，
    校验失败立即断开（此时令牌还没发出），状态栏提示「中转证书校验失败，疑似被拦截」
  - 也支持不经反代、按 IP + 证书指纹直连：`swr://令牌@IP:端口/api?pin=指纹`（服务端设 `RELAY_TLS=1`）
  - 连接串用 Windows DPAPI 按当前用户加密后保存，配置文件被拷走也解不开；输入时圆点掩码显示
  - 「中转连不上时允许直连腾讯」默认关闭：中转不可用时宁可暂停，也不暴露域名
  - 误把连接串贴进搜索框会自动转为连接串输入，不会被当作关键词发出去

## 运行与打包

- **源码运行**：双击 `start.bat`，或运行 `pythonw app.py`（需 Python 3.8+，无需 pip 安装任何包）
- **自检**：双击 `selftest.bat`——检查源码语法、模块导入、代码解析、开盘时间判断，并实测行情/搜索接口，
  逐项显示通过/失败（不启动界面、不改配置）。改完代码或打包前先跑一次
- **GitHub Actions 自动打包**：推送客户端代码后，在仓库 Actions → client-exe → 对应运行的 Artifacts 下载 exe；
  推送标签（如 `git tag v2.0.0 && git push origin v2.0.0`）会自动创建 Release 并附上 exe 和 SHA256 校验值
- **本地打包 exe**：双击 `build.bat`，生成 `dist\StockWatcher.exe`
  > 注意：`dist` 里现有的 exe 是旧版（Qt），需要重新打包才会更新为 2.0
- **开机自启 / 卸载**：托盘或任务栏条右键菜单

| boss_key / disguise_key | 快捷键 |

## 基金

- **场内基金**（ETF / LOF，如 510300、159915、588200）：和股票一样实时行情
- **场外基金**（如 005827 易方达蓝筹）：直接搜名称添加，显示单位净值和日涨幅，面板第二行注明「净值 10-29」；
  若接口在盘中提供估值则显示估值并注明「估值」。净值每天只更新一次，场外基金不会触发高频刷新。
  直接输代码时请加前缀 `jj005827`（纯 6 位数字会被当作股票代码）

## 代码输入规则（直接输代码时）

一般直接搜名称即可；直接输代码时：`600519`→沪、`000001`/`300750`→深、`8xxxxx`/`4xxxxx`/`92xxxx`→北交所、`00700` 或 `hk00700`→港股、
`AAPL` 或 `usAAPL`→美股（以 US 开头的美股如 USB，请输入 `usUSB`）。
