# 盯盘小窗（stock_monitor）

Windows 任务栏盯盘小组件：行情直接显示在任务栏上，鼠标悬停弹出自选面板。
纯 Python 标准库 + ctypes 调用 Win32 API，无第三方依赖。

## 下载与运行

- **下载 exe**：仓库 Releases 页面下载 `NetMonitor.exe`，双击运行
  （文件名、图标、文件属性、进程名、开机启动项、配置目录均为中性名称 NetMonitor，看不出是盯盘工具）
- **源码运行**：双击 `start.bat`，或 `pythonw app.py`（Python 3.8+）
- **首次运行**：面板会弹出「请选择联网方式」——「设置加密中转」或「直连腾讯」。
  选择之前不发出任何网络请求；之后可在右键菜单「高级配置 → 网络方式」中切换
- **开机自启 / 退出 / 卸载**：右键任务栏条

## 任务栏

- 作为任务栏的子窗口显示，与任务栏融为一体：随任务栏自动隐藏，全屏程序时随任务栏让位
  - Win10：嵌入任务按钮区右侧，任务按钮自动让出位置
  - Win11：显示在托盘区左侧
  - 个别系统嵌入失败时自动改用悬浮覆盖方式（右键菜单「高级配置 → 任务栏显示」可手动切换）
- 按住任务栏条左右拖动可微调位置（「高级配置 → 任务栏显示 → 恢复自动位置」还原）
- 深浅色任务栏自动换字色；所有文字常规字重
- **盯哪只**（右键菜单「基础配置 → 任务栏盯哪只」）：
  - 固定盯一只：子菜单里直接选，或在面板里单击某只
  - 轮播：间隔 2~60 秒或自定义；数量可选全部或前 N 只（按面板顺序）；鼠标停在条上时暂停
  - 任务栏显示名称：开关，开启后在涨跌行前显示短名称或别名
- **数值着色**（涨红跌绿）：右键菜单「基础配置 → 数值着色」，默认不着色

## 面板

- 鼠标在任务栏条上停留约 0.2 秒（或单击任务栏条）弹出，移开自动收起
- **常驻**：点面板右上角图钉，再点一次取消；**拖动**标题栏可放到任意位置并常驻，位置自动记住
- 托盘图标左键：临时显示 / 隐藏面板
- 行操作：单击设为任务栏显示；悬停点 × 删除；右键可上移 / 下移 / 移到最前 / 设置别名 / 删除
- **搜索添加**：底部输入框输入名称、拼音首字母或代码（如 `茅台`、`zgpa`、`00700`、`apple`），
  ↑↓ 选择、回车添加；覆盖 A 股、港股、美股、指数、ETF、场外基金；也可一次粘贴多个代码（空格或逗号分隔）
- 跟随系统深浅色和强调色

## 伪装

| 方式 | 效果 | 操作 |
|---|---|---|
| 隐私模式 | 不显示名称、不着色，只显示数字 | 面板标题栏按钮 / 右键菜单「高级配置 → 伪装」 |
| 网速伪装 | 任务栏显示成 `0.775 K/s` 样式，面板显示为进程列表 | 同上 |
| 老板键 | 一键隐藏任务栏条、面板和托盘图标，再按一次恢复 | `Ctrl+Alt+Z` |
| 切换伪装 | 正常 → 隐私 → 网速 循环 | `Ctrl+Alt+X` |

- 伪装模式下托盘图标显示为柱状图标；可在「高级配置 → 伪装 → 伪装时隐藏托盘图标」中隐藏
- 快捷键可在配置文件中修改；忘记老板键时再次运行程序即可恢复显示

## 基金

- 场内基金（ETF / LOF）：与股票相同的实时行情
- 场外基金：搜索名称添加，显示单位净值和日涨幅，面板注明净值日期；每天更新一次

## 刷新与网络

- 只在交易时段按设定间隔刷新（A 股、港股、美股各按自己的时间，含午休，美股按夏令时换算）；
  休市、锁屏、老板键隐藏时不发请求；节假日自动识别
- 场外基金在工作日 18:00~23:30 每 30 分钟查一次净值
- 启动时先显示上次保存的行情，联网后更新；开盘中数据长时间未更新会在面板标题旁提示
- 所有请求均为 https；刷新间隔每次随机浮动 ±20%，网络上看不出固定节拍的轮询规律

## 加密中转（可选）

经你自己的服务器转发行情和搜索请求：网络上看不到腾讯域名和查询内容，
且客户端只用自带的公共根证书清单校验证书，公司或抓包工具装进电脑的根证书无法解密。

1. 部署服务端，见 [server/README.md](server/README.md)
2. 首次运行时点「设置加密中转」（或右键任务栏条 → **高级配置 → 网络方式 → 设置连接串**），粘贴 `swr://令牌@你的域名/路径`，回车
3. 运行 `selftest.bat`，「加密中转服务器」显示校验通过即可

- 开启后行情、搜索全部经中转；中转不可用时暂停请求，不会直连腾讯
  （如需直连兜底，勾选「中转连不上时允许直连腾讯」）
- 连接串用 Windows 账户加密保存，拷到其他电脑无法解密；输入时以圆点显示
- 也支持按 IP + 证书指纹连接：`swr://令牌@IP:端口/api?pin=指纹`（服务端设置 `RELAY_TLS=1`）

## 输入代码规则

`600519` 沪市、`000001` / `300750` 深市、`8xxxxx` / `4xxxxx` / `92xxxx` 北交所、
`00700` 或 `hk00700` 港股、`AAPL` 或 `usAAPL` 美股、`jj005827` 场外基金。

## 配置

`%APPDATA%\NetMonitor\`：`config.json` 配置、`cache.json` 行情缓存、`log.txt` 日志。
三个文件都用 Windows 账户加密（DPAPI），打开只能看到乱码，拷到其他电脑或换用户也解不开；
查看日志：`python selftest.py --log`。

| 键 | 说明 |
|---|---|
| `stocks` / `pinned` | 自选列表 / 任务栏固定显示的那只 |
| `interval` | 刷新间隔（秒） |
| `bar_rotate` / `rotate_top` | 轮播间隔（秒，0 = 不轮播）/ 轮播前 N 只（0 = 全部） |
| `bar_name` / `aliases` | 任务栏显示名称 / 自定义别名 |
| `updown_color` | 涨红跌绿着色 |
| `disguise` | 0 正常 / 1 隐私 / 2 网速伪装 |
| `boss_key` / `disguise_key` | 快捷键 |
| `bar_mode` / `bar_offset` | 任务栏显示方式（embed / overlay）/ 位置微调 |
| `panel_pinned` / `panel_pos` / `panel_topmost` | 面板常驻 / 位置 / 总在最前 |
| `net_mode` / `relay_allow_direct` | 联网方式（空 = 未选择、`direct` 直连、`relay` 加密中转）/ 中转不可用时是否允许直连 |

## 开发

| 文件 | 说明 |
|---|---|
| `app.py` | 主程序：任务栏条、面板、托盘、菜单、热键 |
| `winapi.py` | Win32 ctypes 绑定 |
| `quotes.py` | 行情、搜索、加密中转连接 |
| `selftest.py` / `selftest.bat` | 自检：语法、解析、开盘时间、中转与接口实测 |
| `StockWatcher.spec` / `build.bat` | 本地打包 exe |
| `.github/workflows/client.yml` | 推送客户端代码或手动运行时，自动打包 exe 并发布到 Releases（版本号自动递增） |
| `.github/workflows/relay.yml` | 自动构建服务端 Docker 镜像 |
| `server/` | 加密中转服务端 |

数据来自腾讯公开行情接口，可能有延迟，仅供参考，不构成投资建议。
